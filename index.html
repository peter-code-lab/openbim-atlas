openBIM Atlas Working mockup · v0.2

Mandate trackers list where openBIM is required. This page connects that policy map to documented project outcomes — so the headline isn't a list of countries, it's a relationship: where governments require open standards, measurable value follows.

1 · Policy

Where is openBIM required?

Two different kinds of mandate, often confused: governments requiring openBIM as a client (public procurement) and requiring it as a regulator (building-permit submission & approval). The map shows either one.

2 · Practice

What does openBIM deliver?

Documented, sourced project results — cost, time and carbon savings from real projects (buildingSMART Awards case studies). Shown as orange markers on the map.

3 · The link

Do mandates and value go together?

The correlation this project exists to show: documented value clusters in jurisdictions that mandate open standards. The panel below counts the evidence.

⚠︎  Prototype data — mandate statuses and case outcomes summarised from the project deck and public sources; not yet independently verified or dated to a common reference point.

The correlation, counted

Take every documented value case and ask: what is the mandate status where it happened? If open-standards policy and project value were unrelated, the cases would scatter evenly. They don't — they concentrate where openBIM is required.
